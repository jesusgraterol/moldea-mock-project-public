# Cedar Workshop

Cedar Workshop is a neighborhood maker studio. Staff schedule small-group ceramics and repair classes, track confirmed rosters, and keep a waitlist when a class fills. This repository starts with a short sample schedule so the team can record how the workshop operates before building booking software.

The October wheel-throwing class is full and has three waitlist requests. The workshop manager needs a shared account of the class and booking process that a future developer can understand without relying on the spreadsheet alone.

This is a source-only prototype repository. It does not run a booking service or collect customer information.
