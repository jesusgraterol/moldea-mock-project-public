# Escalation and ownership

This document describes the fictional Parcel Desk explorer fixture.

Use shipment review for uncertain delivery evidence, returns review for product-condition questions, and a support lead for conflicting records. An urgent label requests attention; it does not establish a deadline or a resolved case.
