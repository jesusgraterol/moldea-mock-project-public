# Explorer fixture contract

This document describes the fictional Parcel Desk explorer fixture.

This branch is a visual fixture for the cloud repository explorer. New custom agents, tools, skills, routing, variables, and mirrors are inert local examples. They read checked-in files and return predetermined output; they call no provider, mutate no business system, and send no reply.

## Review example

A fixture may include a complete draft and a missing operational integration at the same time. Review the supplied evidence and the declared requirement separately.
