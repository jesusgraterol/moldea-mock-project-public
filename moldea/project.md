# Saffron Menus

Saffron Menus prepares the weekly printable menu card for the Saffron café. The kitchen records each week's dishes in `menus/week-<week>.json`; the `menu-card` project skill turns that file into `cards/week-<week>.md`.

The card is read by café guests. It must never list a dish, ingredient, or allergen that the menu file does not contain.

- [Menu style](context/menu-style.md): the card's layout and voice.
- [Allergens](context/allergens.md): which allergens the card flags and how.
- [Pricing](context/pricing.md): how dish prices appear on the card.
