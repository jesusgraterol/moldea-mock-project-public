# Catalog Studio

Catalog Studio helps merchandisers at a small home-goods shop draft product descriptions from local fact sheets. The fictional CS-214 and CS-215 records illustrate the source material.

Drafts must distinguish confirmed product facts from unsupported vendor claims and identify unclear points for editorial review. A staff editor decides what, if anything, reaches the storefront. This repository is a source-only prototype, not a working service or publication system.
