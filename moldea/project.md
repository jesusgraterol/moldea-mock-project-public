# Juniper Pantry

Juniper Pantry is a fictional community pantry coordinating volunteer shifts. It serves volunteers and coordinators, with coordinators retaining authority over assignment decisions.

## Operating context

- Volunteer shifts currently last two hours.
- Coordinators approve every assignment.
- Volunteers should ask a coordinator about scheduling exceptions rather than assume those exceptions are approved.

## Project boundaries

The project starts with operating documentation. Application implementation and agent design are outside the current setup scope and require a separate request.

Any software must remain local and credential-free, using checked-in fictional inputs.
