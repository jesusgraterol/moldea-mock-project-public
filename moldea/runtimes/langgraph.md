The exported LangGraph graph takes a supplied alert batch. Its `classify` node loads the canonical `alert-classifier` instruction and calls the structured model supplied as `configurable.reviewModel`; the repository does not configure a provider. The `observe` node keeps original readings and event IDs while normalizing supported latency durations and thresholds to milliseconds for comparison. The `assemble` node separates those observations from model-proposed investigative questions. The graph has no operational action node.
