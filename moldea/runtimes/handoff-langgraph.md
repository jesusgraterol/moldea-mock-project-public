The exported handoff LangGraph graph takes the classifier's structured result. Its `prepare` node builds a timestamp-ordered timeline from raw events, source context, and batch capture time, retaining both original latency readings and their comparable millisecond observations. Its `draft` node loads the canonical `handoff-brief` instruction and calls the structured model supplied as `configurable.synopsisModel`. The model only supplies the synopsis; the graph carries source evidence and prior classification in separate output fields. There is no sending, paging, incident, or production action node.
